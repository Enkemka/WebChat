Web Chat Application

A real-time web chat application built with Spring Boot, MongoDB, and a simple HTML/CSS/JavaScript frontend.
The backend exposes a REST API with JWT authentication and supports secure user login and protected endpoints.

This project focuses on building a scalable backend architecture for messaging systems.
